# Thesis Review Lab

Aplicación de escritorio para escribir y revisar tesis, memorias, papers y presentaciones con agentes de IA.

- **Centro de escritura:** devuelve tu texto (PDF, Word, LaTeX o texto pegado) con anotaciones que explican qué corregir y cómo.
- **Detector de IA:** marca pasajes con señales de texto generado y propone cómo reescribirlos con voz propia. Es un indicio, no una prueba.
- **Comisión de tesis:** un presidente lee tu trabajo, convoca a los revisores que hacen falta (citas, metodología, matemáticas, código, normativa, integridad…) y redacta un acta con veredicto, nota, prioridades y preguntas para la defensa. Puedes conversar con cada integrante sobre su revisión.

Funciona con tu propia API key de Claude, OpenAI, Qwen, Gemini, DeepSeek u OpenRouter, en español o inglés.

## Descargar

Descarga el instalador de la [última versión](https://github.com/Lucas-Zamora-F/thesis-review-lab-releases/releases/latest): el archivo **Thesis-Review-Lab-…-x64-Setup.exe** en *Assets*. Requiere Windows 10 u 11 de 64 bits.

Una vez instalada, la app se actualiza desde **Preferencias → Buscar actualizaciones**.
